# 2D моушн-графика

## Режиссура

1. **Хук за 2 секунды.** Вопрос зрителю или сильный образ. Логотип в начале теряет зрителей.
2. **Одна мысль на сцену.** 3–4 секунды, одна фраза, один главный элемент.
3. **Один герой.** Логотип или продукт проходит через весь ролик, меняя место и форму. Ролик цельный, а не набор слайдов.
4. **Показ вместо рассказа.** Курсор нажимает, цена меняется, отметки ставятся.
5. **Финал-действие.** Кнопка или ссылка ≥ 2 с.

Структура 30-секундного ролика (8 сцен по 4 с при 120 BPM): хук → что это → каталог/масштаб → цена/выгода → как получить → для каких задач → поддержка/доверие → финал.

## Физика движения

| Приём | Как выглядит | Реализация |
|---|---|---|
| Пружина | быстро приезжает, мягко садится, малый перелёт | `stepR(t-t0, w=14, z=.78)` |
| Появление с размытием | сдвиг + blur 14 px → 0 за ~0,15 с | `pop(el,t,t0,dx,dy,blur)` |
| Смена слова | старое вверх с размытием и сжатием, новое снизу | две пружины, старое начинает раньше на 0,1 с |
| Растягивание | передний край быстрее заднего | две пружины с разной жёсткостью (16 и 9) на краях |
| Курсор-нажатие | масштаб 0,84 → 1, кольцо расходится, надпись меняется | `cursor(t,path,press)` |
| Перетаскивание | значение = позиция курсора, после отпускания — пружина | позиция ручки считается из пружины, курсор привязан к ней |
| Счётчик | быстрый набор с торможением | `Math.round(outQ((t-t0)/.7)*N)` |
| Поле с волной | волна цвета от центра, плитки поворачиваются при проходе | расстояние до центра vs радиус волны `(t-t0)*1000` |
| Склейка на удар | смена сцены на сильную долю + вспышка цвета 1 кадр | сцены по 4 с при 120 BPM |
| Эквалайзер | полосы по реальному спектру музыки | спектр трека заранее в массив (40 полос × 120 к/с) |
| Пульс на долю | масштаб +4 % на каждый удар | `kick(t)=exp(-((t%.5))*11)` |

## Типографика

- Заголовки: ультражирный гротеск заглавными (например, Unbounded 900) + акцентное слово курсивом с засечками (Playfair Display Italic) в градиенте бренда. Контраст двух шрифтов делает кадр «дорогим».
- Мелкие подписи и счётчики сцен: моноширинный (IBM Plex Mono), трекинг .14em.
- `word-spacing:.14em` у тяжёлых заглавных, `white-space:nowrap` у кнопок и строк заголовка.
- Минимум 28 px для текста, который нужно прочитать на телефоне (1080p кадр).

## Сетка и рамка

- Поля 48 px, внутренние отступы по сетке 8 pt.
- HUD (уголки, номер сцены, подписи внизу) — тонкий и полупрозрачный, не спорит с главным.

## Тайминг под голос и музыку

- Голос записывать по фразам, тайминги слов — `scripts/words.py`. Ключевое слово появляется в момент, когда звучит.
- 120 BPM: доля 0,5 с, такт 2 с, сцена 4 с = 2 такта.
- Музыка под голосом −4…−6 дБ (автоматическое приглушение по огибающей голоса).

## Проверка

- До рендера: `scripts/snap.py` — по кадру в начале, середине и конце каждой сцены.
- После рендера: `scripts/storyboard.py` — кадр в секунду, ищем мелькания, наложения, пустоты.
