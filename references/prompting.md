# Как промптить референсами

## Главное правило

Из референса берём **движение**, от бренда берём **вид**.

Плохо:
> Сделай как в этом ролике, только с нашим текстом.

Получится копия. Её отклонит заказчик и не примет аудитория.

Хорошо:
```
Сделай ролик 16:9, 30 секунд, о [продукт], в цветах бренда [#...].
Дизайн уникальный. Из референсов возьми только приёмы:
- из ролика 1: смену слов с размытием и вспышку лучей от логотипа;
- из ролика 2: чат, где курсор нажимает кнопку;
- из ролика 3: шторку до/после для сравнения цен;
- из ролика 4: ритм — склейки ровно на удар, тишину перед финалом.
Не бери цвета, шрифты, кадры, персонажей и музыку референсов.
Главный объект — [наш логотип / продукт], он проходит через весь ролик.
Сначала таблица приёмов и 4–6 стиль-кадров, анимация после моего «да».
```

## Что можно и что нельзя брать

| Можно | Нельзя |
|---|---|
| тип перехода между сценами | чужие кадры, картинки, 3D-модели |
| ритм, паузы, удары под музыку | логотипы, персонажей, маскотов |
| поведение текста | фирменные цвета вместе со шрифтами |
| механику показа продукта (курсор, чат, счётчик, до/после) | тексты, слоганы |
| движение камеры | музыку и звуки из ролика |
| роль звуков и тишины | композицию кадр в кадр |
| структуру сцен | |

## Таблица приёмов (делать до стиль-кадров)

| Референс | Приём (точное название) | Как будет у нас |
|---|---|---|
| ролик 1 | вертикальная смена слова с размытием | вопрос-хук, сервисы меняются под голос |
| ролик 2 | шторка до/после с ручкой | старая и новая цена, ручку тянет курсор |
| ролик 3 | поле узора с волной цвета | узор в цветах бренда, в центре главная цифра |

Не знаешь название эффекта — опиши словами и подбери через `animation-vocabulary`.

## Слова

Помогают: «позаимствуй приём», «механику», «переход», «ритм», «движение камеры», «поведение текста», «вместо их X у нас Y».
Вредят: «повтори», «как там», «в том же стиле» без уточнения.

## Проверка на копию

Стиль-кадр рядом с листом референса. Если можно спутать — меняй цвет, композицию или главный объект, пока общим не останется только движение.

## Правки

```
Правки по скриншотам:
1. Цена 380 неверная, правильная 230.
2. В поле ввода курсор под текстом — сделай как в настоящем чате.
3. «40+» прижато влево — поставь по центру плашки.
Остальное не трогай, перерендери только эти сцены.
```
Одна правка — один пункт, скриншот, и отдельно — что трогать нельзя.
