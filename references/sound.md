# Звук

## Голос

- Записывать по фразам, с соседними фразами как контекстом (у ElevenLabs — `previous_text` / `next_text`): интонация цельная, а править можно одну фразу.
- Сложные названия писать так, как они звучат («ЧатДжиПиТи», «ДжемХаб»), в кадре — правильное написание.
- Тайминги слов: `scripts/words.py`.

## Музыка

- Темп ~120 BPM; арка: вступление → рост → провал перед главным моментом → кульминация → финал. Длина = длине ролика.
- Генерация по плану секций (ElevenLabs Music, `composition_plan`), секция не короче 3 с. Или библиотека без отчислений (pixabay.com/music, YouTube Audio Library).
- Под голосом приглушение на 4–6 дБ по огибающей голоса.
- Стерео: музыку расширить через середину/бока (side × 2–2,5).

## Звуки интерфейса

Клик, щелчок, «вжух» на смене слова, тики счётчика, «динь» на отметке, суббас на главных ударах. Ставить ровно на событие в кадре, панорамировать по месту события на экране.

## Громкость

1. Свести, измерить среднюю громкость.
2. Линейно подтянуть к −14 LUFS (соцсети), без агрессивного лимитера.
3. Мягкий лимитер только для пиков, итоговый пик ≤ −1 дБ.
4. Финал на 2–3 дБ громче основной части.
5. `python scripts/loudness.py <файл>` — отчёт и предупреждения.

Замеры не заменяют слух. В отчёте всегда писать, прослушан звук или только измерен.
