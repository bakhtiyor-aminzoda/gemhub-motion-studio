# Уроки из реальных проектов

Каждый пункт — настоящая ошибка, которую заметил заказчик или проверка, и способ её не повторить.

## Креатив и режиссура

| Ошибка | Что сказал заказчик | Как правильно |
|---|---|---|
| Ролик повторил референс 1:1, поменялся только текст | «Нужно было позаимствовать анимацию, переходы, а не копировать. Нам уникальный дизайн нужен» | Таблица приёмов, визуальный язык от бренда, проверка стиль-кадра рядом с референсом |
| Яркие заливки, маскот, конфетти, наклейки | «Слишком по-детски, не профессионально» | Сдержанная палитра, акцентный цвет точечно, крупная типографика, один сильный образ |
| Без голоса, «общая» музыка | «Не хватает голоса, музыка не подходит» | Голос по фразам; музыка с аркой и кульминацией, подобранная под темп сцен |
| Мало движения, слабое начало | «Моушн-графики не хватает. Хук плохой» | Вопрос или сильный образ с первого кадра; один герой меняет форму; событие на каждую долю |
| Ролик похож на интерфейс: вкладки, панели, мелкие подписи | «Очень не красиво» | Один крупный образ на экран; интерфейс только как упрощённая крупная сцена |
| Моношрифт на тёмном фоне без движения | «Это слайд, а не ролик» | Моношрифт только для мелких подписей; заголовки крупные и живые |
| Надпись мелькнула между сценами | «Не успел прочитать» | Каждая надпись минимум 1 с и не попадает под смену сцены |
| Шутка или мем, который надо расшифровывать | «Ужасная идея» | Говорить прямо, что продукт делает |

## Факты

| Ошибка | Как правильно |
|---|---|
| Цены взяты из тестовой базы, а не из живого каталога | Один источник правды; цифры проверять на стиль-кадрах |
| Неверная «официальная» цена конкурента в сравнении | Чужие цены уточнять у заказчика или по официальной странице на дату ролика |
| Округлили «больше 30 сервисов», а их ровно 30 | Числа писать только проверенные, с запасом в правильную сторону |
| Придуманные описания функций продукта | Только общеизвестные функции, сверенные с официальной справкой |
| Обещание, которого нет в условиях («гарантия на весь срок») | Обещания только из условий продажи |

## Вёрстка и код

| Ошибка | Причина | Как правильно |
|---|---|---|
| Текст «40+» прижат в угол, курсор поля ввода под текстом, иконка вылезла из кнопки | Скрытие через `display='none'`, а показ через `display=''` стёр inline `display:flex` | Функция `on()` из шаблона запоминает исходный `display` |
| Плашка уже слова | Измеряли до загрузки шрифта | `document.fonts.load(...)` для всех начертаний до первых измерений |
| Пузырь «печатает…» снова появился после ответа | Функция появления сама включала элемент | Сначала проверить окно времени, потом вызывать появление |
| Слова висели на экране весь ролик | Взяли слово вместо времени из массива таймингов → NaN | Проверять таймингы на NaN; лист кадров по всей длине |
| Хром выглядел плоским серым | Неправильный порядок вершин треугольников и однородное окружение | Порядок вершин против часовой стрелки снаружи; окружение — нарисованная картинка с яркими полосами (`fromEquirectangular`) |
| Тяжёлые заглавные слиплись («ВОДНОМ») | Плотный трекинг у ультражирного шрифта | `word-spacing:.14em` |
| Кнопка разбилась на две строки | | `white-space:nowrap` у кнопок и заголовков |
| Объект наезжал на текст, чат наезжал на заголовок | Не проверили крайние кадры сцен | Лист кадров в начале, середине и конце каждой сцены |
| Логотип обрезан краем кадра | | Отступ от краёв минимум 48 px (1080p) |

## Звук

| Ошибка | Как правильно |
|---|---|
| Музыка ровная, без нарастания, обрывается раньше конца | Генерировать по плану секций (вступление, рост, провал, кульминация, финал), длина = длине ролика |
| Секция музыки 2 с не принималась сервисом | Минимальная секция 3 с |
| Нет выделенного момента (вся дорожка одинаково громкая) | Финал на 2–3 дБ громче основной части; нормализовать линейно, лимитер только для пиков |
| Узкое стерео | Расширить музыку через середину/бока (side × 2–2,5), звуки интерфейса панорамировать |
| Лимитер «съел» кульминацию | Сначала линейная громкость к −14 LUFS, потом мягкий лимитер с запасом, итоговый пик ≤ −1 дБ |
| Сказали, что звук хороший, не слушав | Всегда писать: «проверено замерами» или «прослушано» |

## Производство

| Ошибка | Как правильно |
|---|---|
| Перерендер всего ролика из-за одной правки | Удалять только кадры затронутых секунд (кадр = t × 120) |
| Файл не дошёл на телефон | Лёгкая копия до 30 МБ |
| WebGL не работал в безголовом браузере на Windows | Флаги `--ignore-gpu-blocklist --use-angle=swiftshader --enable-unsafe-swiftshader` (уже в `render.py`) |
| Кракозябры в скриптах с русским текстом на Windows | `PYTHONUTF8=1` |
| Установщик `.ps1` с русским текстом не запускался в Windows PowerShell 5.1 (ошибки разбора) | Сохранять `.ps1` в UTF-8 с BOM |
| Правки разных задач в одном длинном чате | Одна задача — один чат; передавать только цель, решения и состояние |

## Чек-лист перед сдачей

- [ ] Кадры нельзя спутать с референсами; общими остались только приёмы.
- [ ] Первые 2 секунды цепляют без логотипа.
- [ ] Одна мысль на сцену, каждая надпись видна ≥ 1 с.
- [ ] Все цифры и факты из источника заказчика.
- [ ] Нет наложений, обрезанного текста, пустых кадров (раскадровка по секундам).
- [ ] Слова на экране совпадают с голосом, смены сцен — с долями.
- [ ] Громкость около −14 LUFS, пик ≤ −1 дБ, кульминация +2–3 дБ, стерео не узкое.
- [ ] Финальное действие видно ≥ 2 с.
- [ ] Есть лёгкая копия ≤ 30 МБ и нужные форматы (9:16, 16:9, 1:1).
- [ ] В отчёте честно сказано, что проверено на слух, а что замерами.
