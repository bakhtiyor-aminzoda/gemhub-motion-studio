# Бесплатные шрифты для роликов

Скачать любой шрифт Google Fonts в проект: `python scripts/fetch_font.py "Unbounded" 400,700,900` → `fonts/` + готовый `fonts.css`. Шрифты локально = рендер не зависит от интернета.

## Где брать (бесплатно для коммерческого использования, проверять лицензию каждого)

| Источник | Что там |
|---|---|
| fonts.google.com | Сотни шрифтов под лицензией OFL, многие с кириллицей (фильтр Language → Cyrillic) |
| fontsource.org | Те же и другие open-source шрифты пакетами npm |
| fontshare.com | Бесплатные шрифты студии ITF, в основном латиница |
| velvetyne.fr | Экспериментальные open-source шрифты |
| collletttivo.it | Open-source шрифты дизайнеров |

## Проверенные пары для роликов (Google Fonts, есть кириллица)

| Роль | Шрифт | Характер |
|---|---|---|
| Ударный заголовок | Unbounded 900 | широкий, технологичный |
| Ударный заголовок | Russo One | плотный, спортивный |
| Узкий заголовок | Oswald 700 | плакатный, экономит ширину |
| Заголовок / текст | Montserrat 800 | универсальный геометрический |
| Текст интерфейса | Manrope 600–800 | современный, читаемый |
| Текст интерфейса | Inter / Inter Tight | нейтральный, «продуктовый» |
| Текст интерфейса | Onest, Golos Text | созданы с упором на кириллицу |
| Акцент-курсив с засечками | Playfair Display Italic | контраст к гротеску, «дорогой» акцент |
| Акцент / редакционный | Lora Italic, PT Serif Italic | мягче, журнальный |
| Подписи, счётчики, HUD | IBM Plex Mono, JetBrains Mono | технический моно |
| Округлый дружелюбный | Rubik, Nunito | для мягких брендов |

Рабочие сочетания:
- Unbounded 900 + Playfair Display Italic + IBM Plex Mono — технологичный launch.
- Oswald 700 + Inter + JetBrains Mono — плакатный, новостной.
- Montserrat 800 + Lora Italic — универсальный рекламный.

## Правила

- В кадре максимум 2 семейства + моно для мелочей.
- Загружать все начертания до измерений: `document.fonts.load('900 100px Unbounded','АБВ')`.
- Проверять кириллицу каждого начертания: у части шрифтов курсив или жирный без кириллицы.
- Ультражирные заглавные: `word-spacing:.14em`, трекинг −0,02em.
