# Reels, Shorts, TikTok и монтаж съёмки

Главный инструмент — `video-use` (монтаж разговором). Субтитры в стиле бренда — `remotion-captions` или блоки субтитров `hyperframes-registry`. Звук и цвет — `media-use`.

## Виды монтажа и как их делать

| Вид | Как | Инструмент |
|---|---|---|
| Говорящая голова, интервью, подкаст | расшифровка → вырезать паузы, «эээ», повторы → субтитры → хук в начало | video-use |
| Нарезка Reels из длинного видео | найти 3–5 самых сильных мыслей → 30–45 с каждая → вертикальный кроп по лицу | video-use |
| Туториал, скринкаст | ускорить ожидание, зум на клики, подписи шагов | video-use + моушн-вставки |
| Монтаж под музыку (тревел, продукт) | склейки на доли, длина планов кратна такту | video-use + `scripts/beats.py` |
| Рекламный UGC-формат | хук 1–2 с → проблема → продукт → результат → призыв | video-use + субтитры |
| Моушн + съёмка | моушн-вставки рендерить отдельно, вклеивать как клипы | шаблон + video-use |
| Чистый моушн-Reels | весь ролик кодом | шаблон / product-launch-motion |

## Правила Reels

- Хук за 1–2 с: самая сильная фраза или кадр, без логотипа и «привет».
- Субтитры крупные, 2–3 слова, текущее слово выделено, в безопасной зоне (не под интерфейсом площадки: верх ~250 px и низ ~400 px кадра 1080×1920 держать свободными).
- Смена плана каждые 1,5–3 с.
- Финал: призыв + название/ссылка ≥ 2 с.
- Форматы: 9:16 основной, при необходимости 1:1 и 16:9.

## Расшифровка

- video-use: ElevenLabs Scribe (нужен ключ в `.env`).
- Бесплатно и локально: faster-whisper — `scripts/words.py` (время каждого слова).

## Промпт

```
Из interview.mp4 сделай 3 Reels по 30–40 с.
Каждый начинается с самой сильной фразы, без пауз и «эээ».
Субтитры крупные, по 2–3 слова, текущее слово в цвете бренда, в безопасной зоне.
В конце плашка с названием на 2 с.
Сначала покажи список фрагментов с таймкодами, монтируй после моего «да».
```
