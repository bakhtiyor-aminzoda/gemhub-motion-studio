# GemHub Motion Studio

**Один скилл для Claude Code и Codex, который делает креативные ролики без нейрослопа и сам ставит всё остальное.**

Моушн-графика, launch- и рекламные ролики, Reels/Shorts/TikTok, 2D и 3D анимация, кинетическая типографика, монтаж съёмки, субтитры. Скилл работает как режиссёр: выбирает лучший инструмент под задачу (HyperFrames, Remotion, GSAP, product-launch-motion, video-use), ставит его, разбирает референсы по приёмам и проверяет ролик по списку реальных ошибок из коммерческих проектов.

*One skill for Claude Code and Codex: a motion-design director that installs and orchestrates HyperFrames, Remotion, GSAP, product-launch-motion and video-use, turns references into techniques instead of copies, and checks every video against a list of real production mistakes.*

## Установка

```bash
npx skills add bakhtiyor-aminzoda/gemhub-motion-studio -g -a '*'
```

Затем откройте агента в папке проекта и напишите:

```
Используй gemhub-motion-studio и выполни первый запуск.
```

Скилл сам поставит ffmpeg, Python-пакеты, Chromium, faster-whisper, video-use и набор скиллов:

| Что ставится | Для чего |
|---|---|
| heygen-com/hyperframes | HTML → видео, ~450 готовых блоков, media-use (музыка, звук, цвет) |
| remotion-dev/skills | Видео на React, серии по шаблону, субтитры |
| AbubakrChan/product-launch-motion | Режиссура launch-роликов |
| greensock/gsap-skills | Таймлайны анимации |
| emilkowalski/skills | Качество движения, словарь эффектов |
| browser-use/video-use | Монтаж съёмки разговором |
| faster-whisper | Локальная расшифровка и время слов |

Ключ ElevenLabs (голос, музыка, расшифровка) агент попросит и положит в `.env`. Не отправляйте ключи в чаты и не коммитьте их.

## Что умеет

- **Маршрутизация.** Под каждую задачу — свой главный инструмент, без каши из библиотек.
- **Референсы → приёмы.** Листы кадров из любого ролика, таблица «референс → приём → как у нас», шаблон промпта, проверка на копию. Список сайтов с референсами по моушну, 3D, Reels и рекламе.
- **2D моушн.** Пружины, смена текста с размытием, один герой через весь ролик, курсор с нажатиями и перетаскиванием, счётчики, шторки, поля с волной, склейки на долю.
- **3D.** Зеркальные и стеклянные объекты на three.js, смена формы, отражения в цветах бренда; готовые 3D-блоки; Blender для фотореализма.
- **Reels и монтаж.** Нарезка из длинного видео, субтитры, хуки, безопасные зоны площадок.
- **Звук.** Голос по фразам, музыка с аркой, звуки интерфейса, громкость −14 LUFS с кульминацией.
- **Шрифты.** Подборка бесплатных шрифтов с кириллицей и скрипт, который скачивает любой Google Font в проект.
- **Уроки.** `references/lessons.md` — реальные ошибки (копия референса, «детский» стиль, неверные цены, слетевшая вёрстка, плоский 3D, глухой звук) и как их не повторять.

## Скрипты

| Скрипт | Что делает |
|---|---|
| `new_project.py <папка> [w h]` | Новый проект ролика из шаблона |
| `ref_sheet.py <видео> <out.jpg>` | Лист из 24 кадров референса |
| `fetch_font.py "<Шрифт>" 400,900` | Скачать шрифт в проект + `fonts.css` |
| `words.py ph/*.wav` | Время каждого слова в голосе |
| `beats.py music.wav` | Темп и сетка долей трека |
| `snap.py <папка> t1 t2 …` | Лист контрольных кадров |
| `render.py frames 0 30` | Рендер кадров (2 подкадра = размытие движения) |
| `encode.sh <имя> 1280x720` | MP4 60 fps + лёгкая копия |
| `storyboard.py <mp4>` | Раскадровка по секундам и поиск мельканий |
| `loudness.py <файл>` | Громкость, пики, кульминация |
